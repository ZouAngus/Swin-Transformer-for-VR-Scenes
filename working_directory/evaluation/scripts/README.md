# evaluation/scripts/ — as-run records

These shell scripts are the exact commands used to produce the numbers in the
report, preserved verbatim from server2 — they contain server-absolute paths
(`~/action/...`, `~/my_mmaction2/...`) and are NOT meant to run elsewhere
unmodified. The canonical, portable tools live in `working_directory/`
(`infer_long_video.py`, `eval_long_video.py`, `eval_det_cls.py`,
`plot_det_cls.py`) and `aggregate.py` in this folder.
